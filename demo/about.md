# About this server

These are Robin's repositories: small tools, notes and experiments.

- Browse them on the [index](/), or jump to [tinyhttpd](tinyhttpd) and
  [notes](notes).
- Clone over HTTPS, read-only: `git clone https://git.example.com/tinyhttpd`
- Patches are welcome by email: `git format-patch` and `git send-email` to
  robin@example.com.

```sh
git clone https://git.example.com/notes
```
